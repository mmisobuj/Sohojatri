# Sohojatri

This repository is organized into two top-level folders:

- `Backend` - ASP.NET Core backend API and infrastructure
- `Frontend` - Flutter mobile application

## Backend

```bash
cd Backend
dotnet build Sohojatri.slnx
dotnet test Sohojatri.slnx
```

## Frontend

```bash
cd Frontend
flutter pub get
flutter run
```
